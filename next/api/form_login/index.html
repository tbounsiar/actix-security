Form-based Login Example

This example demonstrates form-based login with redirect support, similar to Spring Security’s formLogin().

§Run

cargo run --example form_login

§Test

Open http://localhost:8080 in a browser. You will be redirected to /login page. Login with admin:admin or user:user.
